# Security

Please report vulnerabilities privately through GitHub's security advisory
form once the repository is public. Until then, contact the maintainer listed in
`repository.yaml`.

Do not include a real Home Assistant URL, access token, address, NFC payload,
household catalog, or maintenance history in an issue or reproduction. The
repository accepts fictional examples only.

Production mode is intended to run exclusively behind Home Assistant
Supervisor ingress. Deployments that expose the app directly are unsupported.
